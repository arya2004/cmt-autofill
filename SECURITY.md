# Security

Only the current v2 source is maintained. For sensitive reports, use the private
[security advisory form](https://github.com/arya2004/cmt-autofill/security/advisories/new)
if enabled. Otherwise, open an issue requesting a private contact channel without
exploit details or personal data. No response-time guarantee is offered.

Never include author records, cookies, credentials or tokens. See
[PRIVACY.md](PRIVACY.md) for permission and logging details.

Release workflows use pinned actions, SHA-256 checksums and tag-build provenance.
Checksums detect changes but require a trusted source. Review permissions before
installing the extension.
